# Architecture Decision Records

Architecture Decision Records document important technical decisions and the reason behind them.

Use sequential filenames:

```text
0001-use-flutter.md
0002-use-supabase.md
0003-use-riverpod.md
0004-use-melos-monorepo.md
0005-material3-design-system.md
```

Each ADR should include context, decision, consequences, and links to related tasks or documents.
