# MVP Scope

## Included in the MVP

- Registration and login
- User profile
- Multi-role system
- Branch selection
- Basic SKN infrastructure
- Club creation application
- Club document upload
- Administrator review
- Club profile
- Club branches and sports
- Coach invitation
- Athlete invitation
- Guardian and child matching
- Teams and training groups
- Training creation
- Calendar
- Attendance
- Club announcements
- Basic fee plan
- Payment status tracking
- Basic notification center
- System administration panel

## Not included yet

- Full accounting
- E-invoice
- Live stream
- Live score
- Advanced AI analysis
- Marketplace
- Shipping integrations
- Sponsor marketplace
- Facility reservation
- International federation integrations
- Advanced referee system
